What really runs

A Python HTTP backend, isolated visitor state, graph routing, deterministic flow allocation, policy validation, dry-run preview, approval, rollback, synthetic metrics, forecast-aware routing and a real optional Google API call.

What does not run

No Ryu, Mininet, Open vSwitch, OpenFlow installations, LSTM training, real packet capture, or measured failover benchmark. Exported results describe this mathematical model only. QoS is a priority scheduler model, not configured switch queues.

Try the complete loop

  1. Prioritize video and block p2p. Preview the before/after effects, then approve.
  2. Select s1-s3 in the topology and fail the link. Inspect the new flow paths and decision trace.
  3. Raise demand to 3×. Enable forecast-aware routing and watch paths adapt.
  4. Open change history to restore an earlier configuration.
  5. Export the session evidence as JSON.

Safety and privacy

Management-wide blocks, unrecognized schema fields, contradictions, stale approvals and unreachable routes are rejected. No generated shell commands run. Keep private information out of prompts. Sessions expire after 30 idle minutes and reset on hosted restarts.

Model assumptions

Each simulation step represents one second. Links share capacity in both directions. Traffic is a fixed synthetic workload with a deterministic sinusoidal demand pattern. A strict-priority scheduler gives selected flows first access, with stable flow-ID ordering within each class. Latency is a two-way propagation plus bounded queue-delay estimate; jitter is an illustrative 3% estimate. Forecasts use eight recent utilization samples and a five-step trend. Neither forecasts nor safety checks guarantee a production SLA.

Offline vocabulary

Hosts h1-h8; applications video, voice, web, p2p and dns; optional TCP/UDP port. Use explicit directions and numeric Mbps/ms ceilings. Example: block h1 to h3 on tcp port 80. Offline mode refuses unsupported wording rather than pretending to understand. Allow policies are explicit declarations and cannot silently override blocks.

Built for explanation and exploration, not production network administration. All result claims should retain the model-only qualification.
